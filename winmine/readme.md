The game is played on a 9x9 board with 10 bombs hidden in unknown locations. The goal is to click on all the safe squares, leaving only the bombs remaining on the board. After each square is clicked, a number appears indicating how many bombs are adjacent to it. If a player suspects a square contains a bomb, they can mark it with a flag.

In the hook we implement that at the start of the game, we flag all the bomb positions right away, allowing us to quickly win by then marking all the remaining safe squares.
